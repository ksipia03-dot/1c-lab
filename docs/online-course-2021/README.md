## О курсе

Пять записей онлайн-курса «Основные механизмы платформы 1С:Предприятие 8.3» (30.04–07.05.2021). По каждой лекции сформированы транскрипт и структурированный конспект.

> **Транскрипция:** faster-whisper (`base`), **chunked** (сегменты по 600 с), VAD включён; видео **не обрезается** по началу речи — в транскрипт попадает полная дорожка. Поле `speech_start_sec` из `.speech.json` указывает момент начала речи (для навигации по видео).
>
> **Конспекты:** все пять лекций — **complete**.

## База знаний для агентов

Каталог `docs/online-course-2021/` — **read-only knowledge base** по материалам курса:

- концепции платформы из лекций (архитектура, метаданные, регистры, СКД, бизнес-процессы);
- проверка объяснений по конспектам перед догадками о поведении платформы;
- таймкоды в конспектах и `speech_start_sec` для перехода к месту в исходном MP4.

Для ответов предпочитать **конспекты**; сырые `.json` / `.raw.txt` — только для дословных цитат или глубокого поиска. Файлы транскриптов в workspace **не удалять**.
