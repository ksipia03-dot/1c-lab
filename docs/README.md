## Учебный контур

| Компонент | Где | Статус (2026-08-21) |
|-----------|-----|---------------------|
| Платформа 8.3 **учебная** (`1cv8t` 8.3.27.1688) | `C:\Program Files (x86)\1cv8t\…` | Установлена (UC1) |
| ИБ **ERP25 Учебная** | `C:\1C-Lab\Bases\ERP25_Demo\` | Файловая ИБ есть; **конфиг ERP пустой** (нет `.dt`/`.cf`) |
| Дистрибутивы | `C:\1C-Lab\downloads\` | Учебная платформа OK; ERP на releases — **нет прав** (ISS-001) |
| Документация на сервере | `C:\1C-Lab\docs\` | Зеркало `docs/` |
| Dump конфигурации для Cursor | `C:\1C-Lab\erp-dump\` → `config/erp-dump/` | После загрузки ERP |

Практика в толстом клиенте — на Windows-стенде; разбор метаданных и запросов — в Cursor через MCP (после появления конфигурации ERP).

**Доступ с Mac:** RDP **3389**, SSH **22** (`sshd` на сервере). Подробности: `ai_docs/develop/reports/2026-08-21-server-ports-mac.md`.

## Совместимость ИИ ↔ 1С

Проект проверяет, насколько агенты Cursor могут:

- опираться на правила и skills в `.cursor/`
- читать документацию ИТС и локальные материалы в `docs/`
- работать с выгрузкой метаданных и учебной базой через MCP
- помогать в подготовке к экзамену «Специалист-консультант» (управленческий учёт) **по официальным материалам**

Разбор экзаменационных билетов выполняется отдельно, по одному, после появления официального сборника в `exam/materials/official/`.
