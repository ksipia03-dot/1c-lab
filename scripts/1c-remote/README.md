# Скрипты удалённого Конфигуратора (`1c-remote`)

Пакетный запуск учебной платформы: **`1cv8t.exe`**, не `1cv8.exe`.

## Где запускать

- **Self-hosted runner** на старом сервере 1С — локально, без `-Remote`. Платформа и база уже на этой машине.
- **vdswin2k22** (Cursor) — учебной платформы нет. Необязательный ключ `-Remote` делает `ssh` на алиас `REMOTE_SSH_HOST` (`1c-erp`) и запускает ту же команду Конфигуратора на старом хосте. Если SSH ещё не поднят, скрипты остаются валидными для локального запуска на раннере.

`PLATFORM_PATH` и `INFOBASE_PATH` в `.dev.env` — пути **на старом сервере** (сейчас `C:\Program Files (x86)\1cv8t\8.3.27.1688` и `C:\1C-Lab\Bases\ERP25_MCP`). Новый путь ИБ не придумывать.

## Секреты

Не коммитьте `.dev.env`, пароли, SSH-ключи и токены runner. В `.dev.env.example` только пустые ключи. Скрипты не пишут пароли в лог.

## Импорт на раннере

Из корня checkout на старом сервере:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\1c-remote\Import-Config.ps1
```

Расширение (CFE): добавить `-Extension ИмяРасширения`.
